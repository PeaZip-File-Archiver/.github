## 📖 Project Overview

**PeaZip** is a free and open-source file archiver designed for creating, opening, extracting, managing, and converting archive files.

The application provides a graphical interface for working with compressed files while also offering encryption, file management, archive conversion, integrity verification, and advanced compression options.

PeaZip supports a broad selection of archive formats and provides a practical workspace for everyday file compression and archive management.

---

## ⚙️ Core Features

### 📦 Archive Creation

* Create compressed archives from files and folders.
* Configure compression levels and archive options.
* Add multiple files and directories to a single archive.
* Create split archives for large collections of data.
* Create encrypted archives when supported by the selected format.

### 📂 Archive Extraction

* Extract files and folders from supported archives.
* Extract complete archives or selected items.
* Choose custom extraction locations.
* Preview archive contents before extraction.
* Handle multiple archives through batch operations.

### 🗜️ Compression

* Compress files to reduce storage requirements.
* Select different compression methods depending on the archive format.
* Adjust compression levels according to performance and size requirements.
* Create archives optimized for storage or transfer.

### 🔐 Encryption & Security

* Protect supported archives with passwords.
* Use strong encryption options provided by compatible archive formats.
* Secure sensitive files before storage or transfer.
* Manage encrypted archive contents through the application interface.

### 🔄 Archive Conversion

* Convert archives between supported formats.
* Extract and recompress data using another archive type.
* Process multiple archives through batch workflows.
* Simplify archive-format migration.
